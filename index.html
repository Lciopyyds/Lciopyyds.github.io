Beyond Prompting: Building Auditable Agent Skills for Submitted-Code Complexity Analysis

Developed ComplexitySkill, an auditable agent skill framework combining executable rules, static reasoning, constrained dynamic execution, and regression testing for submitted-code complexity analysis.

Manuscript under submission to NAACL

ONGOING EXPLORATION

Reliable Skill Evolution & Regression Testing

Exploring how changes to skills, tools, prompts, and planning affect evolving LLM agents, with a focus on dependency-aware regression testing and verification-driven updates.

INDEPENDENT UNDERGRADUATE RESEARCH

Empirical time-complexity inference

Supported by Fudan’s Xiyuan undergraduate research program, this project explores growth-rate estimation from execution-time measurements. The workflow combines warm-up elimination, median aggregation, finite-value filtering, multiplicative input scaling, and log-log regression, with a benchmark constructed from accepted Codeforces solutions.

Agent systems & evaluation

Contributed to the skill-evolution workflow in WeiheZhishu, evaluation runs for SEA-Eval, and comparative experiments for GenericAgent.
