Beyond Prompting: Building Auditable Agent Skills for Submitted-Code Complexity Analysis

Developed ComplexitySkill, an auditable agent skill framework combining executable rules, static reasoning, constrained dynamic execution, and regression testing for submitted-code complexity analysis.

构建 ComplexitySkill，将领域知识转化为可执行规则，结合静态推理、受约束的动态执行与回归测试，提升提交代码复杂度分析的可验证性。

Manuscript under submission to NAACL · 投稿中

ONGOING EXPLORATION 持续探索

Reliable Skill Evolution & Regression Testing

Exploring how changes to skills, tools, prompts, and planning affect evolving LLM agents, with a focus on dependency-aware regression testing and verification-driven updates.

BLE indoor localization & privacy ↗

A Python experiment combining k-nearest-neighbor RSSI fingerprint localization with planar Laplace noise on predicted coordinates. It evaluates localization error and noise magnitude across privacy budgets, with code, results, and an experiment report.

以 kNN 完成 RSSI 指纹定位，在预测坐标上注入平面拉普拉斯噪声，对比不同隐私预算下的定位误差与噪声幅度；仓库包含代码、结果和实验报告。
